Beiçola F.I

Este projeto é um site criado para apresentar o nosso time de futsal, o Beiçola F.I.

A ideia foi criar uma página simples e organizada, mostrando um pouco sobre o time, seus jogadores, a camisa e o logo.

O site também possui uma pequena interação em JavaScript ao clicar nos jogadores.
