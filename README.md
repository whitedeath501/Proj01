Beiçola F.I

Site criado para apresentar o nosso time de futsal, o Beiçola F.I.

O site apresenta informações sobre o time, os jogadores titulares e reservas, o logo e a camisa do time.

O projeto foi desenvolvido utilizando HTML, CSS e JavaScript.
